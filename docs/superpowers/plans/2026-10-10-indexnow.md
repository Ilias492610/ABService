# IndexNow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Notify participating search engines about genuine published changes without account access.
**Architecture:** Public root proof plus opt-in CLI; fixed endpoints and registry validation; no browser code.
**Tech Stack:** Node22+ fetch/Response/node:test; Nextpublic assets.
**Spec:** `docs/superpowers/specs/2026-10-10-indexnow.md`

## Global Constraints

- No GSC Wizard, account writes, cost, invented indexing result or automatic retry.
- Explicit published paths only; default preview makes no network calls.
- Fixed canonical host and official IndexNow endpoint; publicly served proof must match beforePOST.
- First live batch is `/foutcodes` and `/foutcodes/remeha` after their deployed content is verified.

## Review Focus

- A foreign URL, noindex path or personal query must fail before any network side effect.
- Redirect, HTML proof, wrong key or unreachable proof must preventPOST.
- 202must not become 'verified/indexed';429must not trigger a submission loop.
- Duplicate paths must not consume redundant crawl requests; empty invocation must not submitall.
- Tests/CI/dry runs must not send real notifications.
